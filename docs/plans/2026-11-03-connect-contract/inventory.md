## 1. Operations (21, all in `backend/api/openapi.yaml`)

Shared shapes: every error body is `application/problem+json` `Problem` (`type`, `title`, `status`, optional `detail`, `code`, `request_id`); 422 is `ValidationProblem` with `errors: [{pointer, code, detail}]`. Every operation can also return 500 `/problems/internal`. Auth: document-level `security: sessionCookie` (`openapi.yaml:14`), overridden by `security: []` on public ops; role from `operationAccess` (`backend/internal/httpapi/authz.go:41-63`). Path `{id}` is `format: uuid` (invalid → 422 `/id`). List ops take `limit` (1–100, default 20) and `cursor` (opaque) query params.
