# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Will413028/fullstack-template/security/advisories/new).
Do not open a public issue.

Include the affected file or endpoint, steps to reproduce, and the impact you expect.
You should get a first response within 7 days.

## Supported versions

Only the latest commit on `main` is supported. Projects created from this template
are maintained separately and need their own security policy.
