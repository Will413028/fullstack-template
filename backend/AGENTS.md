# Backend — Go

Go modular monolith: stdlib `net/http` with an oapi-codegen strict server generated from the contract, pgx + sqlc, Atlas declarative schema, opaque sessions in the database, `log/slog`. Decisions and their reasons: `docs/adr/2026-10-18-go-backend.md` (stack, data layer, DB roles) and `docs/adr/2026-10-18-api-and-auth-baseline.md` (topology, API shape, auth).

## Commands

Run from `backend/`. Needs Go (version in `go.mod`) and Docker (integration tests and the Atlas dev database). Tool versions and checksums are pinned only in `Makefile` and `tools/go.mod`: the Go-built tools (govulncheck, sqlc, oapi-codegen, oasdiff, gocover-cobertura, gotestsum, deadcode) share the module `tools/go.mod` and run as `go tool -modfile=tools/go.mod <name>`, so they never change the application's `go.mod`; never add a tool to `go.mod` itself. A vulnerable dependency of a tool is upgraded in `tools/go.mod`; `make check` shows the tools still produce and detect the same things. CI runs `make check`, so local and CI use the same versions.

```bash
make run                     # serve with backend/.env (format in .env-example)
make test                    # go test -race through gotestsum; integration tests start PostgreSQL 18 with testcontainers
make check                   # everything CI runs: fmt-check gen-check lint deadcode test vuln sqlc-diff drift squawk
                             # migrations-immutable api-breaking tools-selftest
make gen                     # regenerate internal/httpapi/gen from api/openapi.yaml
make sqlc                    # regenerate each module's internal/store from its schema.sql and queries
make migration name=<name>   # generate a migration from the modules' schema.sql (Atlas standard build)
make fmt                     # gofmt -w
```

The binary is one command with subcommands: `app serve`, `app migrate` (applies `migrations/` as the owner role, then grants the app role), `app seed-admin`, `app recover-admin` (new password for an existing admin, enabled, sessions ended, throttle cleared: the way back when no admin can sign in), `app healthcheck`. The only enabled admin cannot be disabled or deleted (`auth.ErrLastAdmin`).

## Layout

```
api/openapi.yaml             # the contract (OpenAPI 3.0.3), embedded by api/embed.go
cmd/app/                     # composition root: config, DB pool, services, HTTP server, subcommands
internal/httpapi/            # handlers, generated server (gen/), validator, problems, auth cookie, authz, middleware
internal/modules/<m>/        # one module: service (<m>.go), schema.sql, queries/*.sql, sqlc.yaml, internal/store (sqlc)
internal/platform/           # shared lower layer: apperr, authctx, config, db, dbtest, hibp, httpx, logx, migrate
internal/archtest/           # layering checks over the import graph
migrations/                  # generated by Atlas; atlas.sum is its checksum file
atlas.hcl                    # Atlas env: src globs internal/modules/*/schema.sql, auth first
scripts/                     # CI checks: schema drift, immutable migrations, squawk, breaking changes, coverage
```

Modules: `auth` (users, sessions, login throttling, password checks) and `items` (the CRUD example).

## Rules

1. **The contract is the single source.** Paths, shapes, lengths, formats and enums live only in `api/openapi.yaml`. The validator middleware enforces them before a handler runs; the frontend uses types generated from the same file. Do not repeat a limit in a handler, a service or zod. After changing the contract run `make gen` here and `pnpm gen:api` in `frontend/`; CI fails when either generated file differs.
2. **Layering** (depguard in `.golangci.yml`, `internal/archtest`): `internal/modules/<m>` never imports `net/http`, `internal/httpapi`, `cmd` or another module; `internal/platform` imports neither modules nor `internal/httpapi`. Handlers translate between generated types and module types in `internal/httpapi`. The current user reaches modules through `internal/platform/authctx`.
3. **Errors.** Services return `*apperr.Error` (a kind plus a stable `code`) for expected failures and plain errors for everything else. `internal/httpapi/problem.go` is the only place that turns them into RFC 9457 problems; unexpected errors become a 500 whose details stay in the log. Handlers do not build problems or choose status codes for failures.
4. **SQL only through sqlc.** Every query is in `internal/modules/<m>/queries/*.sql`; `make sqlc` generates `internal/store`. A hand-written pgx `Query` fails lint (forbidigo): generated code is what closes the rows and checks `rows.Err`. A module's queries never select from or join another module's tables; the only cross-module foreign key is to `users`.
5. **Schema only through Atlas.** Edit the module's `schema.sql`, then `make migration name=<name>`. DDL is hand-written only to replace a generated change that squawk flags for locking with lock-free steps (`NOT VALID`, then `VALIDATE CONSTRAINT` in the next file), and `make drift` must still pass; a pure data backfill is the other hand-written migration. Both use `atlas migrate new`. Every foreign key to `users` cascades or sets null, so deleting an account removes what it owns (`TestForeignKeysToUsersAllowDeletion`). Migrations merged into `main` never change (`make migrations-immutable`); squawk checks locks (`make squawk`). Database rules: `docs/rules/database-design.md`.
6. **Authorization in queries.** A user-owned resource's queries always carry the owner condition, so another user's row is a 404, never a 403. Who may call each operation (public, any user, admin) is `operationAccess` in `internal/httpapi/authz.go`: every operation must be listed and the public ones must match the contract's `security: []`, or the server does not start. `requireRole` rejects non-admins before the handler runs.
7. **Every returned URL can be read.** A 201's `Location` is a path with a GET in the contract, and every path with PATCH, PUT or DELETE also has a GET (`TestEveryWritablePathHasGet`). API rules: `docs/rules/api-design.md`.
8. **Sessions.** The session cookie is `HttpOnly` (`__Host-session`, or `session` when `COOKIE_SECURE=false`); `http.CrossOriginProtection` wraps the whole mux. A feature that changes a user's role or password must revoke all of that user's sessions.
9. **Time.** Code reads the time from the injected clock (`auth.Config.Now`, `httpapi.Deps.Now`); only `cmd/` and tests call `time.Now`, `time.Since` or `time.Until` (forbidigo). Resource tables' `created_at`/`updated_at` come from the database's `now()` (`docs/rules/database-design.md`, 時間戳記).
10. **Tests.** Behavior is tested through HTTP against a real PostgreSQL (`internal/platform/dbtest`, testcontainers) with the same DB roles as production. Follow `internal/httpapi/items_test.go`. Every package with tests has a `TestMain` that fails on a leaked goroutine: `dbtest.Main` for database tests, `goleak.VerifyTestMain` otherwise (`internal/archtest` checks this). `make deadcode` fails on a function that neither the binary nor a test reaches.

## Adding a module

Use `/add-module <name>` (empty skeleton) or `/add-crud <entity> --fields "..."` (full CRUD resource); both follow the `items` module. The steps: contract paths and schemas in `api/openapi.yaml`, `schema.sql` (Atlas picks it up by glob), queries and `sqlc.yaml`, the service, handlers in `internal/httpapi`, wiring in `cmd/app/main.go`, then `make gen sqlc migration name=<name>`, `pnpm gen:api`, tests, and `make check`.
